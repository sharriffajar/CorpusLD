# Benchmark Results Directory

This directory stores evaluation metrics, structured Schema.org JSON-LD outputs, and the visual evaluation studio dashboard generated by the CorpusLD Benchmark Suite.

### Directory Contents:

- **`dashboard.html`**: Interactive, master-detail HTML visual studio dashboard with latency analytics, 8-dimension invariant inspection, and 1-click clipboard exports.
- **`benchmark_history.json`**: Historical run records, latency logs, and aggregated benchmark scores.
- **`*.json`**: Complete Schema.org JSON-LD outputs per evaluated PDF document.

### Viewing the Dashboard:
Open [`dashboard.html`](dashboard.html) directly in any modern web browser or run:
```bash
# Windows
start benchmark_results/dashboard.html

# macOS
open benchmark_results/dashboard.html

# Linux
xdg-open benchmark_results/dashboard.html
```
